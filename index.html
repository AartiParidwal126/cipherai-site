A missed Office Action deadline can cost a patent. Yet the dates are still read by hand from long PDFs and typed into a docket.

From PDF to approved date in three steps

Built for the person who has to be sure, not the person who has to be fast.

  1. Read

    Upload the Office Action PDF. CipherAI extracts the document type, application number, mailing date and response period.

  2. Verify

    Open the source for any field. The exact quote and page appear, with the part used in the calculation highlighted.

  3. Approve

    A reviewer confirms each field, gives a reason for any edit, and approves. The decision is written to an audit log.

Designed to fail safely

When CipherAI is unsure, it says so and hands the decision to a person.

Source on every field

Exact quote, page number and the highlighted value, so a date can be checked in seconds.

Dates calculated by code

The date is worked out by plain code, never guessed. Weekends roll to Monday, month-ends are handled, and the working is shown.

Refuses to guess

If a document shows two different mailing dates, or has no readable text, CipherAI returns no value and asks a person to check.

A person decides

Approval stays locked until each source has been opened. Every edit needs a reason.

Stays on your computer

In the current prototype the PDF is read locally and is not saved. Only an audit-log entry is written.
